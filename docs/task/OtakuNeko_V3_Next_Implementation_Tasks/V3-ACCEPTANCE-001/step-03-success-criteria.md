# V3-ACCEPTANCE-001 Step 03 RFC-106 Success Criteria

## Evidence Matrix

### Multiple agents cooperate

Prove at least two controlled handoff scenarios, loop prevention, and per-agent
capability policy.

### Memory improves over time

Prove durable typed memory changes a later response while remaining editable,
deletable, and user-isolated.

### Capabilities are modular

Prove a capability can be registered and exposed to an allowed agent/MCP client
without modifying agent routing or MCP domain code.

### Tasks run proactively

Prove a persisted scheduled task runs exactly once after restart and can be
paused by its owner.

### AI-assisted evolution is sustainable

Prove task templates, tests, evaluation gates, trace diagnostics, and rollback
instructions are present and exercised by CI.

## Acceptance

Publish a table linking every claim to a command, test name, and result artifact.
An item with missing evidence is incomplete, not “partially passed”.
