# 聊天流式渲染性能优化实施计划

目标：将流式输出从“每个 SSE token 更新持久化 Store”改为“帧级合并更新内存预览，终态一次持久化”，并减少消息树与滚动的无效工作。

## 验收标准

- 连续多个流式 chunk 在同一动画帧内只产生一次预览更新。
- 流式预览更新不触发 `useChatStore` 的 `persist` 写入。
- 完成、停止和报错时仍然将最终消息写入聊天 Store。
- 仅当前流式消息重新渲染，历史消息不因每个 chunk 重建。
- 相关 Vitest、TypeScript 检查通过。

## 执行步骤

1. 为帧级批处理器写失败测试，验证合并、取消和重复调度行为。
2. 实现批处理器，接入 `useChatStreaming`；将中间态移至 hook 内存状态。
3. 在 ChatPage 合并流式预览，使用 selector 缩小 Store 订阅，并为滚动增加帧级调度。
4. 将消息行提取为 memo 组件，避免历史消息在流式过程中重渲染。
5. 运行相关测试、类型检查和 diff 审查。
